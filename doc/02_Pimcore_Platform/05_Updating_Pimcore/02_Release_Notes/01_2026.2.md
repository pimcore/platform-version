# Release 2026.2

Here you will find the important new features and release notes of the Platform Version 2026.2 release.
Please also make sure to run all migrations after update as always.

## Most Important New Features

### Pimcore Studio: Saved Search, Dark Theme, Translation Split Screen & more

This release focuses on stabilizing Pimcore Studio based on partner and customer feedback — key issues have
been fixed and important workflows optimized. On top of that, this release also brings a set of new features:

- **Saved search** — save, share, update, and re-run searches across users, so search configurations can be
  reused instead of rebuilt each time.
- **Translation Split Screen for Data Objects** — maintain multiple languages at once, comparing, editing, and
  updating localized content side by side in a single view.
- **Theme Manager** — replaces the core `Appearance & Branding` settings with a full theme manager: define multiple
  named themes, each with its own token set and branding (background shade, brand color, logo, login background),
  extend the catalog with custom token sets from other bundles, and set a system-wide default that users can
  override per profile. Ships with `Pimcore Light` and `Pimcore Dark` built in. See the
  [Theme Manager docs](https://github.com/pimcore/backend-power-tools-bundle/tree/2026.x/doc/30_Theme_Manager)
  for configuration and customization details.
- **Dashboard widgets** — new widgets for data quality and workflows, plus general dashboard improvements.
- **Entity Ownership Management** — admins can reassign or delete ownership of user-owned Studio configurations
  (saved searches, dashboards, bookmark lists, etc.), so leaving users don't leave orphaned configs behind and
  the workspace stays centrally manageable.

## General

- **Single issue repository**: going forward, all issues are consolidated in the `/platform-version` repository.
  Public issues can be reported directly there; issues containing non-public information should be reported via
  the Enterprise Portal. See the [announcement discussion](https://github.com/orgs/pimcore/discussions/19189)
  for background.
- **Software Bill of Materials (SBOM)**: starting with 2026.2, an SBOM is provided with each platform version
  release, delivered in the `/platform-version` repository. [Download the SBOM for
  2026.2](https://github.com/pimcore/platform-version/releases/download/v2026.2.0/sbom.json).
- **Security fixes**: several security fixes have been applied across all supported and LTS versions of Pimcore.
  Update to the latest available version.

## Additional Changes

### Core Framework

- **CDN integration**: new core events support cache invalidation on a CDN for individual assets and
  thumbnails. Pimcore ships a Fastly implementation out of the box, and the integration is pluggable for other
  CDN providers via a single interface.
- The legacy file-based maintenance-mode backward-compatibility layer (deprecated static helpers on
  `Pimcore\Tool\Admin` and the `var/config/maintenance.php` fallback) has been fully removed. Use the
  `Pimcore\Maintenance\Mode\MaintenanceModeHelperInterface` service instead.
- The `admin` translation domain (`Translation::DOMAIN_ADMIN`) and related translator internals are deprecated
  and will be removed in a future release.
- Minimum requirement of `friendsofsymfony/jsrouting-bundle` bumped to `3.6.0`.

### Pimcore Studio

Mostly refinements this release, no breaking changes: Advanced Columns refinements (context menu, additional
fields), a searchable language-selection dropdown, Data Importer mapping autofill, and the ability to merge
conflicting entries when importing translation files.

### Data Hub & Adapters

- **Data Hub**: added an optional `published` system field argument for data object mutations.
- **Data Hub File Export**: fixed duplicate file exports occurring with multiple Messenger workers, and a
  corrupted export filename edge case.
- **Data Hub Productsup**: improved Studio adapter-configuration permissions (read-only when the user lacks
  update rights, delete option hidden) and fixed a regression from a missing admin event subscriber.
- **Data Hub Simple REST** and **Data Hub Webhooks**: minor Studio permission fixes; no breaking changes.

### TinyMCE Bundle

- Added support for TinyMCE v8.

### Generic Data Index

- Improved reliability of index-queue dispatching between concurrent indexing workers, and fixed a bug where a
  rollback did not properly clean up queue entries.

### Customer Management Framework

- Security fixes: `ORDER BY` column names are now properly quoted in both the classic and Studio customer
  views, preventing a SQL injection risk. Updating promptly is recommended.

### Backend Power Tools
- Bookmark lists are now a supported entity type for Entity Ownership Management.

### Headless Documents
- Studio configuration is now read-only for users without update permission.
