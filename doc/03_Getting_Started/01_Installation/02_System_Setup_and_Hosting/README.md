# System Setup and Hosting

This section covers file storage, database replication, and performance optimization
for hosting a Pimcore application.

Web server configuration, file permissions, database creation, and additional tools
are already covered by the pre-configured Docker environment shipped with the
[installation packages](../README.md) — see the skeleton
[`.docker` directory](https://github.com/pimcore/skeleton/tree/2026.x/.docker) and
[`docker-compose.yaml`](https://github.com/pimcore/skeleton/blob/2026.x/docker-compose.yaml)
as a working reference for your own hosting setup.
